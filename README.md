# DermaCure — ديرماكيور | موقع العيادة

موقع عربي RTL متعدد الصفحات لعيادات **DermaCure — ديرماكيور** للجلدية والتجميل، مبني بـ
**Next.js (App Router) + TypeScript + Tailwind CSS v4** ومُعدّ كتصدير ثابت إلى GitHub Pages.

---

## التشغيل

```bash
# المتطلبات: Node.js 22+
npm install
npm run dev                   # التطوير على http://localhost:3000

# فحوصات ما قبل النشر
npm run typecheck
npm run lint
npm test

# إنشاء مجلد static export محلياً
GITHUB_PAGES=true npm run build
```

## البنية

```
src/
  app/
    page.tsx                  # الرئيسية
    services/                 # /services و /services/[slug]
    doctors/                  # /doctors و /doctors/[slug]
    book/ how-to-book/ working-hours/ faq/ contact/ location/ privacy/
    sitemap.ts, robots.ts, not-found.tsx
  components/
    layout/                   # Header (Mega Menu + قائمة هاتف), Footer, FloatingActions
    services/                 # ServiceCard (اختيار + تنقّل), ServicesBrowser (فلترة وبحث)
    doctors/ booking/ working-hours/ contact/ faq/ ui/
  data/                       # المصدر المركزي
    services.ts               # الخدمات الرسمية التسع + 3 مجموعات
    doctors.ts                # الأطباء الستة
    siteConfig.ts             # الأرقام، العنوان، ساعات العمل، التكاملات، التنقل
    faq.ts, types.ts
  lib/validation.ts           # تحقق من تاريخ ووقت الحجز في المتصفح
  tests/data.test.ts          # Vitest — 31 اختباراً
```

يُبنى الموقع كتصدير ثابت في مجلد `out/`. سير العمل `.github/workflows/verify-static-export.yml`
يشغّل الفحوصات ويتأكد من نجاح التصدير عند تحديث `main`. تُنشر ملفات `out/` في المجلد
`dermacure-clinic-website-development-pages/` ضمن فرع `gh-pages` لمستودع Pages الرئيسي.

**ملاحظة:** أُزيلت صفحة/قسم «الأقسام الثلاثة» بالكامل (المسارات والروابط والبيانات) بطلب
العميل، وحلّت محلها **مجموعات الخدمات** الثلاث داخل `services.ts` (وتُستخدم في فلاتر صفحة
الخدمات وفي قائمة الخدمات الكبرى وفي صفحة تفاصيل الخدمة).

## قرارات تخص المعلومات غير المؤكدة

- **الصور:** أُضيفت ثلاث صور توضيحية مقتصة من تسجيل الشاشة الذي أرسله المستخدم، في
  `public/images/clinic/`. الصور توضيحية وليست صوراً موثقة لعيادة DermaCure. لا توجد صور مولّدة
  بالذكاء الاصطناعي، وبطاقات الأطباء تبقى Placeholder لعدم توفر صور رسمية لهم.
- **ربط الأطباء:** الاستشاريون الأربعة (تخصص: طب الجلدية والتجميل والعلاج بالليزر) مرتبطون
  بالخدمات الجلدية/التجميلية الرسمية التسع. الأخصائيان بلا ربط مؤكد (المسمى قيد التأكيد)
  وتظهر رسائل «قيد التحديث» بدل اختراع العلاقات.
- **ساعات العمل:** 13:00–21:00 يومياً (تعليمات إدارة العيادة)، وحالة «مفتوح الآن» تُحسب
  بتوقيت `Asia/Riyadh` عبر `Intl.DateTimeFormat`.

## الحجز والتواصل على GitHub Pages

- لا يشغّل GitHub Pages خادم Next.js أو PostgreSQL؛ لذلك لا توجد واجهات `/api` ولا تُحفظ بيانات
  النماذج في الموقع.
- نموذج الحجز يجهّز رسالة واتساب تتضمن تفاصيل الطلب. نموذج التواصل يجهّز رسالة مشابهة؛ يفتح
  الزائر الرابط ثم يراجع الرسالة ويضغط «إرسال» يدوياً في واتساب.
- فتح واتساب لا يعني إرسال الرسالة أو تأكيد الموعد. لا تدخل معلومات صحية حساسة في الرسائل.

## الاختبارات

```bash
npx vitest run
```

الاختبارات تغطي: عدد الخدمات وقائمة أسمائها الرسمية،
تفرّد المعرّفات والـ slugs، عرض كل الخدمات في الرئيسية، تغطية المجموعات، عدد الأطباء (6)
وأسماءهم، تبادلية علاقات الطبيب/خدمة، الأخصائيان بلا علاقات، جدول الدوام ومنطقته الزمنية،
الأرقام الرسمية وروابط `tel:` و`wa.me` لكل رقم، العنوان الرسمي، ورفض التواريخ/الأوقات/
الأرقام غير الصالحة، وإلغاء مسار الأقسام.

تشغّل إجراءات GitHub Actions فحوص النوع وESLint والاختبارات قبل إنشاء التصدير الثابت. يتطلب
البناء متغير `GITHUB_PAGES=true` لضبط مسار المستودع الفرعي.
